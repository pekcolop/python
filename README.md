# Python File Sorter

A Python program that automatically organises files into folders based on their file type.

## Features

- Automatically sorts files into categories
- Supports multiple file extensions
- Creates folders automatically when needed
- Uses Python's pathlib and shutil libraries

## Technologies

- Python
- pathlib
- shutil

## What I learned

This was my first Python project. I learned how to work with files and directories, use loops and conditional statements, and automate repetitive tasks using Python.
